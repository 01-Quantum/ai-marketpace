How to explain this

  1. Model owner receives ciphertext datasets only.

  2. Enclave runs encrypted inference—model never sees plaintext.

  3. Encrypted result is stored and returned to the user for decryption.

Privacy by design.
Security by default.

Inference happens in enclave Computation occurs inside a secure enclave.
